# SOC Lab 1 – Network Scan and Traffic Analysis

## Overview
This project demonstrates basic network scanning and traffic analysis using Nmap and Wireshark.

## Tools Used
- Nmap
- Wireshark
- Kali Linux

## Steps Performed
1. Performed network scan using Nmap
2. Identified open ports and services
3. Captured network traffic using Wireshark
4. Analyzed TCP and HTTPS communication

## Key Findings
- Open port: 9050 (tor-socks)
- Observed TCP and TLS traffic
- Identified secure communication on port 443

## Learning Outcome
This project helped me understand how network scanning and traffic monitoring works in real-world environments.
